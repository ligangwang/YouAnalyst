# Adaptive Intelligence UI — implementation record

## Audit and baseline
- Next 16.2.1 / React 19.2.4 App Router; Tailwind 4 utilities and component CSS modules. No new UI framework.
- Existing SiteNav, BrandLogo SVG lettering, CompanySearch, comparison disclosure/color controls, calendar groups/event cards, and left/center/right intelligence workspace are reused.
- Chart: Three.js screen-space lines/bar meshes. Universe: React Three Fiber + Drei CameraControls, d3-force-3d layout. Physics and data topology remain unchanged.
- Existing theme: MarketProvider, pre-paint bootstrap, CSS data-theme selectors; only dark/light, default dark. Account API accepts dark/light. System mode is added as a device preference, retaining that API schema.
- Existing tokens duplicated across globals (--background/--color-shell), calendar/graph (--ui-*), and Explore-local palettes. Central semantic tokens provide compatibility aliases; page modules consume those instead of separate palettes.
- Typography used Sora and IBM Plex Sans with local next/font. Replaced with self-hosted Geist Sans/Mono variable fonts from geist 1.8.1 (SIL OFL), preserving logo artwork and CJK system fallbacks.
- Baseline: 36 screenshots (six pages × three viewports × two themes), captured before edits in output/design-refresh/before. Sizes: 1440×900, 1024×768, 390×844. Public read-only payloads populate the local app; no credentials, writes or generated market data.
- Functional baseline: Compare stock/date editor, line/bar, playback, sharing and auth gates; Companies search/rank links; Calendar month/week, filters, ET conversions and agenda; Explore graph/rails/selection/source links; About contacts; signed-out Watchlist auth gate.

## Review steps
1. Foundations: central tokens, locally hosted typography, pre-paint System/Dark/Light; no backend contract changes.
2. Shell and pages: navigation alignment, search-first Companies, editorial About, compact calendar.
3. Compare: chart-first presentation, compact disclosure controls and secondary community attribution.
4. Explore: theme-aware rails and explicit light/dark graph materials; preserve camera/context and geometry.
5. QA: theme persistence/state continuity, contrast, keyboard, reduced motion, mobile overflow, regression suites and build.

No production deployment is part of this preview. The earlier calendar/About fixes remain in the parent branch/PR #1028.


## Delivered implementation
- Foundations: `src/app/globals.css`, `layout.tsx`, three Geist font/license assets, `src/lib/preferences.ts`, MarketProvider/context and `theme-select.tsx`. Semantic tokens feed existing CSS-module and Tailwind screens through compatibility aliases. Logo lettering and primary tagline are preserved.
- Shell/basic pages: `site-nav.*`, `basic-pages.module.css`, Companies/About routes, CompanySearchCard/search styles and MostConnectedCompanies. Search and real coverage/rankings remain unchanged; company names use Sans and numeric metadata uses Mono.
- Calendar: `earnings-calendar.*`, `earnings-event-card.tsx`. Shorter compact labels retain the source qualifier, Beijing assumption and date-only/TBD distinction; full labels remain in titles and the agenda. Coverage caveat, ET conversions and all controls remain.
- Compare: `stock-compare-page.tsx`, its module, `stock-comparison-chart.tsx`, `compare-community.*`. Chart context/baseline and manual stock-editor collapse are retained; favorite attribution is a secondary disclosure with original author/replay/discussion links. Palette updates modify existing Three.js materials instead of rebuilding the WebGL renderer. Existing source colors are not adjusted or recolored to imply performance.
- Explore: `company-graph-3d.tsx`, `ai-knowledge-graph.module.css`, intelligence rail/summary/legend/activity styles, layer filters, industry-tree style and TreeStarField. Dark mode uses 900 stationary background stars (previously 2600), restrained glow and existing galaxies. Light mode omits background stars/galaxies and uses darker smaller node cores/rings and blue-gray edges. Theme changes update uniforms/materials on the same graph, without touching layout, camera, graph identity, market caps, physics or source semantics.
- Shared timeline legends, inputs, warnings, focus, disabled and reduced-motion states use the shared theme. Normal UI labels were raised to 12px where practical; zoom-scaled graph labels keep their existing contextual sizing.

## Choices, limits and follow-up
- Five reviewable steps are kept in separate commits instead of five separate PRs. The first four cover foundations, basic pages, Compare and Explore; the fifth covers QA refinements and evidence. Foundation and integrated production builds passed. Definitive before/after evidence is the final gallery rather than transient hot-reload captures.
- System mode and explicit header appearance selection persist on the device. Existing account dark/light settings still restore unless a device choice takes precedence. The account API/storage contract remains dark/light; account language and price-color saves are unchanged. This avoids adding a new backend enum/schema in a visual-only change.
- The local helper proxies only public GET APIs and blocks writes; no account credentials or private writes are connected. Server-side featured comparison selection is unavailable locally without database configuration, while public comparison posts and market data load through the read-only proxy. Authentication/account flows are regression-tested in isolated mocks, not represented as live authenticated local sessions.
- Resource continuity/draw-call checks and the reduced star count guard rendering cost. Hardware FPS, battery, and low-end physical-device profiling remain follow-up validation; software WebGL timings are not presented as a hardware performance claim.
- Reproducible read-only launcher: `scripts/design/local-preview.mjs` (run after starting the built Next app on 127.0.0.1:3000). The capture scripts, gallery and image artifacts stay local in `output/design-refresh`; the helper is not included in production routes. UI source is isolated on `codex/adaptive-intelligence-ui`, based on PR #1028. There are no new Firestore collections, API changes, migrations, paid model calls, schedule changes or production deployment.
- Before any eventual deployment, also address the previously recorded old-revision cutover 500s from the prior unrelated release. No traffic changes are performed here.

The final Compare labels and Explore desktop captures were refreshed after final typography/spacing checks.
